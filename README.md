# Adventure Works Sales Analysis Dashboard | Power BI

##  Project Overview
This project presents an interactive Adventure Works Sales Analysis Dashboard built using Microsoft Power BI. It helps analyze business performance through sales, revenue, profit, customer, product, and geographical insights.

##  Project Objectives
- Analyze total revenue and profit.
- Monitor total orders and customers.
- Understand product performance.
- Analyze customer demographics.
- Track returns and return rates.
- Identify geographical sales performance.
- Monitor monthly and yearly business trends.

##  Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Visualization

##  Dashboard Pages

### 1. Adventure Sales
Main sales dashboard providing an overview of sales performance.

### 2. Performance Report
Analyzes business performance using revenue, profit, orders, customers, and return rate.

### 3. Sales Overview
Displays sales trends, quantity sold, total cost, returns, and category-wise orders.

### 4. Customer Details
Analyzes customer information, gender, education, income level, and revenue contribution.

### 5. Product Details
Provides product-level insights, average product price, profit margin, product costs, and top-performing products.

### 6. Map Analysis
Visualizes geographical performance using continent, country, region, and profit.

##  Key Performance Indicators (KPIs)
- Total Revenue
- Total Profit
- Total Orders
- Total Customers
- Total Products
- Total Returns
- Return Rate %
- Profit Margin %
- Average Order Value
- Revenue per Customer

##  Key Business Insights
- Understand overall sales and profitability.
- Identify top-performing products.
- Analyze customer purchasing patterns.
- Compare geographical performance.
- Monitor product returns.
- Support data-driven business decisions.

##  Conclusion
This Power BI project demonstrates how data analytics and interactive visualizations can transform business data into meaningful insights. It helps understand sales performance, customer behavior, product trends, and profitability.
